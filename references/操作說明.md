# 審片台操作說明（給審片的人）

[English: user-guide.en.md](user-guide.en.md)

你不需要會剪輯，也不用安裝任何東西。打開網址，看片，把想改的地方寫下來。

## 一分鐘版

1. 按 **▶ 播放**，或直接拖時間軸。
2. 看到想改的地方就停下來，在影片下方的格子寫意見，按 **在 0:19 加上意見**（數字是你停的時間）。
3. 全部寫完，點開 **我寫的意見**，按 **複製全部意見**，貼回你和 AI 的對話。
4. 覺得這一版可以了，按 **✓ 核准這個版本**，再按一次確認。

## 畫面上有什麼

**播放器（最上面）**
- ▶ 播放／暫停。
- ⏮ 上一畫面、下一畫面 ⏭：一次跳一個鏡頭。正在一個鏡頭中間時，「上一畫面」會先回到這一鏡的開頭。
- −5 秒、+5 秒：往回、往前跳。
- 1×：點一下換播放速度，1× → 1.5× → 2×。
- ＋ 標記這裡：先在這一秒插一支旗子，不用馬上寫字，影片繼續播。
- 滑鼠移到影片上會出現整支片的總覽時間軸，可以直接拖；手機上點一下畫面就出現（同時會播放或暫停）。
- 鍵盤：空白鍵播放／暫停，左右方向鍵前後跳 2 秒。

**這個畫面（電腦在右邊，手機在下面）**
停在哪一個鏡頭，這裡就寫這一鏡的資料：第幾段、多長、怎麼做的、素材從哪來、這時候的旁白和字幕。想知道「這張圖是 AI 畫的還是實拍」看這裡。

**前後畫面**
目前這一鏡和它前後幾鏡的縮圖，點一下就跳過去。

**魚骨時間軸**
整支片從左到右排開。上面是每個鏡頭的縮圖，顏色代表類別（上方有圖例）；中間是聲音的大小；下面是字幕。可以左右拖。你寫過意見的地方會有一個有編號的小圖釘。

## 寫意見的三種方式

| 你想做的事 | 怎麼做 |
|---|---|
| 這一秒有問題 | 停在那裡，寫字，選類別（畫面／聲音／字幕／節奏／其他），按「在 0:19 加上意見」 |
| 先看完整支片再說 | 邊看邊按「＋ 標記這裡」。看完點開「我寫的意見」，在每個標記的格子補上字 |
| 跟某一秒無關的意見（例如整體太長） | 寫字後按「加為整支片的意見」 |

每一則意見還可以：
- **設為整片意見**：表示「不只這裡，整支片類似的地方都要檢查」。
- **刪除**：寫錯了就刪。要按兩次（第一次會變成「確定刪除？」）。

你打的字當下就存在這台裝置，重新整理、不小心關掉分頁都不會不見。

## 把意見交給 AI

**本機模式**（網址是 `127.0.0.1` 或 `localhost` 開頭）：點開「我寫的意見」→「複製全部意見」→ 貼回對話。AI 收到的每一則都帶著時間、鏡頭名和素材來源，例如：

```
[0:19｜鏡頭 5〈店門口〉｜自製，無外部素材] 招牌的字太小
```

**雲端模式**（一個正式網址，頁首有「← 全部影片」）：按「傳給 AI」。意見會存在網站上，換手機或電腦都看得到。按完回對話說一聲「我傳了」，AI 不會自己被叫醒。

## 核准

- 「✓ 核准這個版本」要按兩次才生效：第一次會變成「確定核准？再按一次」，4 秒內沒按就自動取消，避免手滑。
- 核准後可以撤回。
- 核准是綁版本的。AI 出了新版本，舊版的核准不會跟過去，新版要重新看、重新按。
- 只有你自己按的才算。AI 不會、也不該替你按。

## 常見狀況

| 狀況 | 怎麼辦 |
|---|---|
| 影片是黑的、一直轉圈 | 等幾秒讓它載入；還是不行就重新整理。請 AI 確認是用網址開的，不是直接點檔案 |
| 換了一台電腦，意見不見了 | 本機模式的意見只存在原本那台的瀏覽器。回原本那台複製，或請 AI 改用雲端模式 |
| 按「複製全部意見」沒反應 | 文字會出現在意見輸入框裡，手動全選複製 |
| 標記寫了字，但清單上還是空的 | 字已經暫存在這台裝置。按「把寫好的標記一次送出」，或直接按複製／傳送，會一起帶出去 |
| 時間軸太長不好找 | 用播放器上的總覽時間軸拖，或按「下一畫面」一鏡一鏡跳 |

## 隱私

本機模式下，影片和意見都只在你這台電腦，不會上傳。頁面只會向 Google Fonts 要字型檔（連不上就用系統字型）。雲端模式的影片放在架站的人自己的網站空間，沒設密碼的話，拿到網址的人都看得到。
